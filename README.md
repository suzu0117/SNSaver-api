# Update `.env`

Find the request whose `x-fb-friendly-name` is `PolarisProfilePostsTabContentQuery_connection`.

Update the following values in `.env`:

| `.env`          | Request header |
| --------------- | -------------- |
| `IG_COOKIE`     | `cookie`       |
| `IG_CSRFTOKEN`  | `x-csrftoken`  |
| `IG_APP_ID`     | `x-ig-app-id`  |
| `IG_USER_AGENT` | `user-agent`   |
